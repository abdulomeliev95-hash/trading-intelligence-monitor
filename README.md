# 📈 Trading Intelligence Monitor (TIM)

Простое веб-приложение на Python, которое следит за акциями и криптовалютами, показывает интерактивные графики,
считает технические индикаторы, находит базовые паттерны и присылает уведомления в Telegram **с картинкой графика**.

> ⚠️ **Важно.** Приложение не отправляет реальные ордера и не управляет деньгами. Для подтверждённых
> сигналов оно ведёт бумажные сделки с заданным риском. Это не финансовая рекомендация.

## Возможности

- Дашборд: цены, изменение за 5 минут / 1 час / 24 часа (зелёный — рост, красный — падение), активные алерты.
- Интерактивные свечные графики Plotly: 15m, 1h, 4h, 1d, объём, EMA 20/50, уровни поддержки и сопротивления,
  маркеры паттернов, RSI 14, MACD, ATR 14.
- Обнаружение событий: резкий рост, резкое падение, всплеск объёма, бычий пробой, медвежий пробой,
  потенциальный разворот тренда.
- Telegram: команды `/start /help /watchlist /alerts /status /test` и уведомления с PNG-графиком.
- История алертов в SQLite (сохраняется после перезапуска).
- Список активов можно менять, пороги — настраивать.
- Фоновый сканер проверяет паттерны на 15m, 1h, 4h и 1d. 1m/5m не являются таймфреймами стратегии.
- Акции из категории equity в Polymarket Perps подгружаются автоматически; их свечи и данные текущего watchlist остаются раздельными.
- Подтверждённый направленный сигнал открывает paper-сделку: риск 2% виртуального капитала, цель 3R; результат проверяется по стопу/цели без выхода по времени.
- Журнал показывает открытый и реализованный P&L. Значения расчётные, без комиссий, funding, спреда и проскальзывания.

План данных, ML/replay и интеграции Polymarket описан в [ML_PLAN.md](ML_PLAN.md).

## Что понадобится

- Компьютер с Windows, macOS или Linux и доступ в интернет.
- Python **3.11 или новее** (проверено на 3.14).
- Аккаунт Telegram (для уведомлений; без него приложение тоже работает).

## 1. Установка Python

Проверьте, не установлен ли Python уже:

```bash
python --version      # Windows
python3 --version     # macOS / Linux
```

Нужна версия 3.11 или выше. Если Python нет или он старый:

**Windows**
1. Скачайте установщик на https://www.python.org/downloads/
2. При установке **обязательно отметьте галочку «Add python.exe to PATH»**.
3. Откройте новое окно PowerShell и снова проверьте `python --version`.

**macOS**
- Скачайте установщик с https://www.python.org/downloads/ или выполните `brew install python`.

**Linux (Ubuntu/Debian)**
```bash
sudo apt update
sudo apt install python3 python3-venv python3-pip
```

## 2. Подготовка папки проекта

Положите все файлы проекта в одну папку `trading-intelligence-monitor` (структура выше) и откройте в ней терминал.

- Создайте пустые папки `data` и `charts`, если их ещё нет.
- Папка `.streamlit` начинается с точки. В macOS Finder такие папки скрыты: `Cmd + Shift + .` показывает их.

## 3. Виртуальное окружение

Виртуальное окружение хранит библиотеки проекта отдельно от остальной системы.

**Windows (PowerShell)**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```
Если PowerShell пишет, что выполнение скриптов запрещено, один раз выполните
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` и повторите активацию.
Либо используйте обычную командную строку (cmd): `.venv\Scripts\activate.bat`

**macOS / Linux**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

Если всё хорошо, в начале строки терминала появится `(.venv)`.
**Каждый раз, когда открываете новый терминал, активируйте окружение заново.**

## 4. Установка зависимостей

При активном окружении:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

Для запуска тестов дополнительно (необязательно): `pip install pytest`

> Библиотека `kaleido` (версия 0.2.1) нужна для картинок графиков в Telegram.
> Chrome отдельно ставить не нужно.

## 5. Настройка Telegram (необязательно, но рекомендуется)

Приложение работает и без Telegram, но тогда уведомлений не будет.

### 5.1. Создайте бота через BotFather

1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите «Start».
2. Отправьте команду `/newbot`.
3. Введите название бота (любое) и username (должен заканчиваться на `bot`, например `my_tim_alerts_bot`).
4. BotFather пришлёт **токен** вида `123456789:AAExampleExampleExample`. Скопируйте его.

> 🔒 Токен — это пароль к вашему боту. Никому его не показывайте и не публикуйте.
> Если токен утёк, в BotFather отправьте `/revoke`, чтобы получить новый.

### 5.2. Создайте файл `.env`

Скопируйте шаблон:

**Windows (PowerShell / cmd)**
```
copy .env.example .env
```
**macOS / Linux**
```bash
cp .env.example .env
```

Откройте `.env` в любом текстовом редакторе и вставьте токен (без кавычек и пробелов):

```
TELEGRAM_BOT_TOKEN=123456789:AAExampleExampleExample
TELEGRAM_CHAT_ID=
```

`TELEGRAM_CHAT_ID` пока оставьте пустым.

### 5.3. Узнайте свой Chat ID

1. Запустите приложение (раздел 6): `streamlit run app.py`.
2. В Telegram откройте своего бота, нажмите **Start** (или отправьте `/start`).
   Бот не может написать вам первым, поэтому это обязательный шаг.
3. Бот ответит сообщением, где есть строка **`Your chat ID: 123456789`**. Скопируйте число.
4. Остановите приложение (`Ctrl + C` в терминале) и впишите число в `.env`:

```
TELEGRAM_CHAT_ID=123456789
```

5. Запустите приложение снова.

> Для группы: добавьте бота в группу и отправьте там `/start`. ID группы начинается с минуса
> (например `-100123456789`).

> Не запускайте две копии приложения с одним токеном одновременно: Telegram разрешает только одному
> процессу получать команды бота.

## 6. Запуск приложения

При активном окружении, из папки проекта:

```bash
streamlit run app.py
```

Браузер откроется сам. Если нет, перейдите на http://localhost:8501.
При первом запуске Streamlit может спросить e-mail: просто нажмите Enter.
Первая загрузка занимает 5–15 секунд, потому что скачиваются данные по всем активам.

Фоновый монитор и Telegram-бот запускаются отдельным процессом. Откройте второй терминал в папке проекта,
активируйте то же виртуальное окружение и запустите worker:

```bash
python worker.py --local-sqlite
```

Эта команда подходит, если `DATABASE_URL` не задан: веб-приложение и worker используют общую локальную
базу `data/tim.db`. Если в `.env` задан `DATABASE_URL` Supabase/PostgreSQL, запустите вместо этого:

```bash
python worker.py
```

Для проверки Telegram сначала отправьте боту `/start`, возьмите chat ID из ответа, задайте
`TELEGRAM_CHAT_ID` в `.env` и перезапустите процессы. Затем нажмите **Send test notification** в интерфейсе
или отправьте боту `/test`. Тестовое сообщение проверяет доставку; обычные алерты приходят только при
возникновении подходящего подтверждённого сигнала.

Чтобы остановить локальный запуск, нажмите `Ctrl + C` в обоих терминалах.

После правок перезапустите оба процесса. Не запускайте одновременно несколько worker с одним Telegram-токеном.

## 7. Как пользоваться

В приложении три вкладки:

| Вкладка | Что показывает |
|---|---|
| 📊 Dashboard | Таблица watchlist (цена, 5m / 1h / 24h изменения, возраст данных), активные алерты за последние 60 минут. 5m здесь только ценовой показатель, не таймфрейм сигналов. Обновляется каждые 60 секунд. |
| 📈 Chart Analysis | Выберите актив и таймфрейм. Свечи, объём, EMA 20/50, уровни S/R, маркеры паттернов, RSI, MACD, ATR и список найденных событий. |
| 🔔 Alerts & Patterns | Вся история алертов с фильтрами по активу и типу. |

### Добавление и удаление активов

В боковой панели слева:

- **Add asset**: введите тикер Yahoo Finance и нажмите «Add asset».
  Акции: `AMZN`, `GOOGL`. Криптовалюты всегда с суффиксом `-USD`: `DOGE-USD`, `XRP-USD`.
  Приложение проверяет, что по тикеру есть данные, и только потом добавляет его.
- **Remove asset**: выберите тикер и нажмите «Remove asset» (в списке должен остаться хотя бы один актив).

### Пороги алертов

В форме «Alert thresholds» (значения по умолчанию):

| Параметр | По умолчанию |
|---|---|
| Криптовалюты: изменение цены | 2 % за 5 минут |
| Акции: изменение цены | 1 % за 15 минут |
| Всплеск объёма | в 2 раза выше среднего за предыдущие 20 свечей |
| Пауза между повторными алертами | 30 минут |

Нажмите «Save thresholds». Фоновый монитор подхватит новые значения в следующем цикле.

### Типы событий и статусы

| Тип | Как определяется |
|---|---|
| Rapid Price Increase / Decrease | Изменение цены больше порога за заданное окно (по 5-минутным свечам). |
| Volume Spike | Объём последней **закрытой** 5-минутной свечи ≥ порога × среднего объёма 20 предыдущих свечей. |
| Bullish Breakout / Bearish Breakdown | **Закрытая** свеча закрылась за уровнем S/R больше чем на 0,25 ATR. |
| Potential Trend Reversal | MACD пересёк сигнальную линию против тренда (EMA20 vs EMA50), а RSI недавно был в зоне ≤ 35 или ≥ 65. |

Статусы паттернов:

- **Confirmed**: пробой подтверждён объёмом (не менее 1,5× среднего за 20 свечей).
- **Potential**: цена закрылась за уровнем, но объём не подтвердил (возможен ложный пробой), либо это возможный разворот.

В Telegram отправляются: резкие движения цены, всплески объёма и **подтверждённые** пробои.
«Potential»-события сохраняются в истории и видны в приложении, но в Telegram не отправляются.
Фоновый монитор проверяет рынок раз в минуту, пока приложение запущено.

Одинаковые алерты не дублируются: действует пауза (cooldown) 30 минут для одного актива, типа, таймфрейма и статуса,
а одна и та же свеча никогда не создаёт один алерт дважды.

## 8. Проверка Telegram-уведомлений

Любой из способов:

1. В боковой панели откройте «📨 Telegram notifications» и нажмите **Send test notification**.
2. Или отправьте боту команду `/test`.

Вы должны получить сообщение с графиком первого актива из watchlist. Если график не удалось построить,
придёт текстовое уведомление с пометкой, что график недоступен.

Команды бота:

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Приветствие, ваш Chat ID, список команд |
| `/watchlist` | Активы и последние цены |
| `/alerts` | Последние 5 алертов |
| `/status` | Состояние монитора, пороги |
| `/test` | Тестовое уведомление с графиком |

Каждое уведомление содержит: название актива, текущую цену, процент изменения, таймфрейм, индикаторы,
объяснение события и PNG-график со свечами, EMA 20/50, объёмом, уровнями S/R и маркерами паттернов.

## 10. Источник данных и ограничения

- Данные берутся из Yahoo Finance через библиотеку `yfinance`. Это **неофициальный** источник.
  Котировки могут запаздывать, а иногда данные недоступны. Приложение не называет их real-time.
- Время последней свечи и возраст данных показаны на дашборде и в подписи под графиком.
  Строки со старыми данными помечаются как **Stale** (например, биржа закрыта).
- Если данных нет, показывается понятное сообщение. Значения не выдумываются.
- История внутридневных свечей у Yahoo ограничена. Для таймфреймов 5m и 15m она короткая
  (дни или недели), поэтому уровни S/R на них считаются по небольшому окну.
- Алерты создаются **только пока приложение запущено**. Если компьютер ушёл в сон или вы закрыли терминал,
  мониторинг останавливается. Закрытая вкладка браузера мониторинг не останавливает.
- Паттерны — упрощённые эвристики, а не прогноз. Ложные срабатывания неизбежны.

## 11. Частые проблемы

| Проблема | Что делать |
|---|---|
| `command not found: streamlit` | Не активировано окружение. Выполните команду из раздела 3. |
| Нет данных / ошибка Yahoo Finance | Подождите минуту (возможен лимит запросов). Затем `pip install -U yfinance` и перезапуск. |
| Бот не отвечает на `/start` | Проверьте токен в `.env` (без пробелов и кавычек) и перезапустите приложение. На странице есть блок «Telegram notifications» с диагностикой. |
| Ошибка про конфликт getUpdates / 409 | Запущена вторая копия приложения (или другой скрипт) с тем же токеном. Закройте лишнее. |
| Уведомления приходят без картинки | Не сработал Kaleido. Выполните `pip install kaleido==0.2.1` и перезапустите. Текст при этом всё равно доходит. |
| Алертов нет | Это нормально, если рынок спокоен или закрыт. Для проверки временно уменьшите пороги (например, 0,3 %) или нажмите «Send test notification». |
| Порт 8501 занят | `streamlit run app.py --server.port 8502` |
| После правки `app.py` ничего не изменилось | Полностью перезапустите приложение (`Ctrl + C`, затем `streamlit run app.py`). |
